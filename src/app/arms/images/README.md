# Heraldic drawings of the coat of arms generator

Wikimedia Commons SVGs, taken from Category:English_heraldic_dictionary and
Category:SVG_versions_of_images_from_Complete_Guide_to_Heraldry_(book) (A. C. Fox-Davies, 1909).
Optimised with `svgo` (precision 1, ids prefixed, metadata removed) - otherwise unchanged.
`arms-images.ts` is generated from these files: `node scripts/build-arms-images.mjs`.
